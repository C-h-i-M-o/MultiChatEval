# v2 阶段 1：账号体系与权限控制设计

> 归档说明：本文档是 v2 历史设计文档。v2 已冻结，React 替代 Vue 的历史重构文档见 `../react-rewrite/`。

最后更新：2026-06-11

## 1. 目标

阶段 1 建立开放注册、登录、退出、当前用户、普通用户与管理员权限隔离，并将评测任务、反馈和评论归属到真实登录用户。

本阶段同时支持公开和私有评测：

- 公开评测：所有已登录用户可以在历史任务中查看、反馈和评论。
- 私有评测：只有创建者可以查看、反馈和评论。
- 管理员不通过普通任务接口查看其他用户的私有评测。

用户 token 额度字段、用量流水和限制逻辑统一留到阶段 3。

## 2. 认证方案

- 密码使用 Argon2 哈希，不保存或返回明文密码。
- 登录成功后由后端签发 HS256 JWT，并写入 HttpOnly Cookie。
- JWT 包含 `sub`、`iat` 和 `exp`，默认有效期为 8 小时。
- Cookie 使用 `HttpOnly`、`SameSite=Lax` 和 `Path=/`；生产环境启用 `Secure`。
- 阶段 1 不增加刷新令牌、数据库会话表和独立 CSRF Token，前后端按同源方式部署。

公开接口只有健康检查、注册和登录。其余业务接口均要求登录。

## 3. 用户与角色

用户角色：

- `user`：普通用户。
- `admin`：管理员。

用户状态：

- `active`：允许登录和使用系统。
- `disabled`：禁止登录和继续使用已有登录态。

开放注册创建的用户固定为 `user` 和 `active`。首个管理员通过命令行脚本创建，不提供默认管理员密码。

## 4. 接口与权限

认证接口：

- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/auth/logout`
- `GET /api/auth/me`

模型接口：

- `GET /api/models/available`：已登录用户读取可用于评测的精简模型列表。
- `/api/admin/model-configs`：管理员读取和维护完整模型配置。
- `/api/admin/model-configs/test`：管理员测试模型连接。

评测接口继续使用 `/api/evaluation` 前缀，但必须注入当前用户。新建任务写入当前用户 ID 和 `visibility`。

历史任务列表返回所有公开任务，以及当前用户创建的私有任务。私有任务详情或其回答资源被其他用户访问时统一返回 404，避免暴露资源是否存在。

## 5. 数据迁移

- `users` 增加 `role`、`status` 和 `last_login_at`。
- `evaluation_tasks` 增加 `visibility`，默认 `public`。
- 旧任务和旧会话中为空的 `user_id` 迁移为匿名用户 `id = 0`。
- 匿名用户状态设置为 `disabled`，不能用于登录。
- 旧匿名任务保持公开，不归属到任何新注册用户。

## 6. 前端行为

- 新增登录页和注册页。
- 应用启动时调用 `/api/auth/me` 恢复登录态。
- 未登录访问业务页面时跳转登录页。
- 普通用户不显示模型配置入口；管理员可以访问模型配置页。
- 评测表单提供公开/私有选择，默认公开。
- 历史任务展示创建者和公开状态。
- 退出登录后清除认证状态并返回登录页。

## 7. 验收标准

- 用户可以注册、登录、退出并恢复登录态。
- 普通用户访问管理员接口返回 403，未登录访问受保护接口返回 401。
- 管理员可以维护模型配置。
- 公开任务可被其他登录用户查看，私有任务只对创建者可见。
- 任务、反馈和评论正确记录当前用户。
- 用户不能删除其他用户的评论。
- 旧匿名数据保持可用并归属匿名用户。
